# Extra Vehicles (Geode)

Incluye:
- Portal Pelota Rebote y portal Serpiente (fisica propia)
- Portales de velocidad x0.2, x0.4, x2, x3 y x7
- Sonidos, particulas y texturas propias
- Triggers mas faciles: grupo automatico al colocarlos

IDs de objeto: 7001 a 7007.

## Como compilar
1. Instala el Geode CLI y el SDK: `geode sdk install` (y `geode sdk install-binaries` si hace falta).
2. Abre una terminal dentro de esta carpeta.
3. Ejecuta: `geode build`
4. El archivo `.geode` queda en la carpeta `build/`. Copialo a `geode/mods` de tu Geometry Dash.

Si sale algun error de compilacion, mandame el texto completo del error y lo arreglo.
